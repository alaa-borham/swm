# القرارات المطلوبة قبل التشغيل والبنود المؤجلة

## 1. قرارات تُحسم من المؤسسة (القسم 1 من الوثيقة)

كل بند قابل للضبط من «الإعدادات» دون تعديل الكود، ما لم يُذكر غير ذلك.

| القرار | الوضع الحالي في النظام | أين يُضبط |
|---|---|---|
| اسم المؤسسة وبلد التشغيل والعملة والمنطقة الزمنية | قيم افتراضية (ريال، Asia/Riyadh، منزلتان) | الإعدادات |
| إعدادات الضرائب والتقريب | 0% افتراضيًا، أسعار غير شاملة، ضريبة المشتريات قابلة للاسترداد، التقريب لكل بند | الإعدادات (صلاحية الضرائب) + ضريبة كل صنف |
| عدد المستخدمين والمستودعات ونقاط البيع وحجم البيانات | غير محدود في التصميم؛ اختبار الحمل بـ 3,000 صنف و20,000 فاتورة | يُعاد القياس بالأرقام الفعلية |
| هل المندوب يبيع أم يحصل أم ينقل البضاعة، وهل يحتفظ بمخزون أو عهدة نقدية | مدعوم: مخزون خاص وعهدة نقدية وبيع وتحصيل | إنشاء المندوب وربط المستخدم |
| وحدات الأصناف ومعاملات التحويل ودقة الأصناف الموزونة | لكل صنف وحدة أساس ودقة 0–3 منازل وأي عدد من الوحدات | شاشة الصنف أو الاستيراد |
| نوع قارئ الباركود وطابعة الإيصالات ومقاس الطباعة وبيانات الفاتورة | قارئ يعمل كلوحة مفاتيح؛ إيصال 80 مم وA4؛ بيانات المؤسسة والتذييل | الإعدادات + اختبار على الأجهزة |
| نقل أرصدة العملاء والموردين والمخزون والصندوق | استيراد Excel بمعاينة وتحقق، وأرصدة افتتاحية بمستندات مؤرخة | الاستيراد / الأرصدة الافتتاحية |
| آخر يوم مسموح للبيع قبل الانتهاء | يُباع حتى تاريخ الانتهاء نفسه (0 أيام منع) | الإعدادات: «منع البيع قبل الانتهاء بـ» |
| حد الخصم للكاشير | 10% افتراضيًا، ويمكن تحديد حد لكل صنف | الإعدادات + الصنف |
| خطة العمولة | نسبة من التحصيل المؤهل قبل الضريبة لكل مندوب، بتاريخ سريان | صفحة المندوب |
| وتيرة النسخ الاحتياطي ومكان النسخة الخارجية | يومي مع الاحتفاظ بـ 30 نسخة على الخادم | الإعدادات + جدولة نسخ خارجية (دليل التشغيل) |
| التقنية والاستضافة | Node.js وSQLite على خادم واحد في المؤسسة أو خادم سحابي صغير خلف HTTPS | دليل التشغيل |

## 2. قرارات تشغيلية اعتُمدت في التنفيذ (وفق اختيارات الوثيقة المبدئية)

- التشغيل متصل بخادم مركزي واحد.
- استلام المشتريات واعتماد فاتورتها عملية واحدة بعد التأكد من الاستلام الفعلي.
- المبيعات تخصم المخزون عند اعتماد الفاتورة؛ لا توجد طلبات مؤجلة أو حجوزات.
- التحويل بين المستودعات أو إلى مخزون المندوب حركة داخلية فورية لا تُعد بيعًا.
- كلمات المرور 8 أحرف على الأقل بأرقام وحروف، وتغيير كلمة المرور المؤقتة إلزامي.
- النقد في الصناديق لا يسمح بالصرف بأكثر من الرصيد الدفتري (البنك مستثنى).
- مرتجع المبيعات يُعتمد بصلاحية «اعتماد مرتجع»؛ الكاشير ينشئه للمراجعة.
- اعتماد الجرد والتالف للمدير افتراضيًا ويمكن منحه لأدوار أخرى بتعديل الأدوار في `src/core/permissions.js`.
- التصدير إلى PDF يتم من نافذة الطباعة في المتصفح («حفظ كـ PDF»)، والتصدير إلى Excel وCSV مباشر.
- التحويل فوري افتراضيًا، ويمكن اختيار «النقل على مراحل» لكل تحويل.

## 3. التوسعات

### نُفذت بعد النسخة الأولى

| التوسعة | ما نُفذ |
|---|---|
| الفروع المتعددة | إدارة الفروع، فرع لكل مستند، تقييد المستخدم بفرعه، تصفية التقارير ولوحة الإدارة حسب الفرع، عنوان الفرع في الفواتير |
| طلبات الشراء والاستلام الجزئي | طلب شراء معتمد، فواتير استلام مرتبطة بالمتبقي، منع تجاوز المطلوب، الإلغاء يعيد المتبقي، إغلاق الطلب بسبب |
| النقل على مراحل | بضاعة بالطريق غير متاحة في الطرفين، استلام في الوجهة، النقص خسارة موثقة |
| العمل دون اتصال | نقطة البيع تعمل بلا شبكة بكتالوج محلي، طابور مبيعات بمعرف عملية ثابت ومزامنة تلقائية، صفحة للمرفوض. قاعدة حل التعارض: الخادم هو المرجع؛ ما يرفضه (نقص رصيد، حد ائتماني، صلاحية) يبقى للمراجعة اليدوية |
| تطبيق للمندوب | النظام قابل للتثبيت كتطبيق (PWA) على الجوال ويعمل دون اتصال لنقطة البيع؛ لا يوجد تطبيق أصلي منفصل في المتاجر |
| أجهزة خارجية | باركود الميزان (الوزن أو السعر داخل الباركود)، قارئ الباركود، الطابعة الحرارية |
| الفوترة الإلكترونية | رمز QR بصيغة TLV للفاتورة المبسطة (المرحلة الأولى في السعودية) |
| القوائم المالية | قيود يدوية مقيدة، ميزان مراجعة، دفتر أستاذ، مركز مالي |

### ما زال مؤجلًا (يحتاج حسابات أو جهات خارجية أو قرارًا من المؤسسة)

| التوسعة | سبب التأجيل وما يتطلبه |
|---|---|
| متجر إلكتروني للعملاء | واجهة عامة واستضافة ونطاق وبوابة دفع وسياسة توصيل وحجوزات مخزون |
| الربط مع بوابات الدفع وأجهزة نقاط البيع البنكية | حساب تاجر لدى البنك/البوابة ومفاتيح ربط واختبار مع مزود الخدمة |
| الرسائل النصية أو واتساب للعملاء | حساب لدى مزود رسائل وموافقة على القوالب |
| الفوترة الإلكترونية المرحلة الثانية (الربط والتوقيع) | تسجيل الجهاز لدى الجهة الضريبية وشهادات التوقيع ومتطلبات بلد التشغيل |
| تطبيق أصلي في متاجر التطبيقات | حسابات مطوّر Apple/Google؛ البديل الحالي هو التثبيت من المتصفح |
| ربط مع برنامج محاسبي خارجي | تحديد البرنامج وصيغة التصدير أو واجهة الربط |

## 4. ملاحظات صيانة

- خطة السعر مرتبطة بفترة سريان؛ تغييرها لا يغير العمولات المحتسبة سابقًا.
- تغيير اسم الصنف أو سعره أو معامل التحويل لا يغيّر المستندات التاريخية (تُحفظ نسخة في كل بند).
- حذف الطرف أو الصنف أو المستخدم المرتبط بمستند ممنوع؛ يُستخدم الإيقاف.
