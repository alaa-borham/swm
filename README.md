# نظام إدارة مؤسسة مواد غذائية

نظام عربي (من اليمين إلى اليسار) يعمل من المتصفح على الكمبيوتر والجوال، ينفذ النسخة الأولى من وثيقة المشروع:
الأصناف ووحداتها والباركود، المستودعات ومخزون المناديب، الدفعات وتواريخ الانتهاء، المشتريات والسداد، البيع ونقطة البيع والتحصيل،
المرتجعات، الجرد والتالف، المناديب وعهدهم وعمولاتهم، المصروفات، الصناديق والبنوك والورديات، التقارير، الصلاحيات وسجل التدقيق، والنسخ الاحتياطي.

إضافة إلى توسعات بعد النسخة الأولى: الفروع المتعددة، طلبات الشراء والاستلام الجزئي، النقل على مراحل (بضاعة بالطريق)،
العمل دون اتصال لنقطة البيع وتثبيتها كتطبيق على الجوال، باركود الميزان، رمز QR للفاتورة الضريبية المبسطة،
والقيود اليدوية وميزان المراجعة ودفتر الأستاذ والمركز المالي، ورسائل واتساب للعملاء عبر Meta Cloud API.

## التقنية

| الجزء | الاختيار | السبب |
|---|---|---|
| الخادم | Node.js 20+ و Express | تشغيل بسيط على خادم واحد أو جهاز في المؤسسة |
| قاعدة البيانات | SQLite (better-sqlite3) بوضع WAL | ملف واحد سهل النسخ والاستعادة، ومعاملات ذرية تمنع البيع المزدوج |
| الواجهة | HTML/CSS/JavaScript بدون إطار | تعمل دون إنترنت خارجي، خفيفة على الأجهزة |
| Excel | exceljs | الاستيراد مع المعاينة والتصدير |

المبالغ تُخزن أعدادًا صحيحة بأصغر وحدة للعملة، والكميات بوحدة الأساس × 1000؛ لا توجد أعداد عشرية عائمة في الحسابات.

## التشغيل السريع

```bash
npm install
npm test                 # 46 اختبارًا تشمل اختبارات القبول الخمسة عشر
npm start                # يعمل على http://localhost:3000
```

عند أول تشغيل يُنشأ المستخدم `admin` بكلمة مرور مؤقتة تُطبع في الطرفية (أو حددها مسبقًا بالمتغير `ADMIN_PASSWORD`)، ويُطلب تغييرها بعد الدخول.

**نسيت كلمة مرور admin؟** أضف المتغير `ADMIN_RESET_PASSWORD` (8 أحرف على الأقل) في Railway وأعد التشغيل؛ تصبح كلمة مرور admin هي هذه القيمة (ويُفك القفل ويُطلب تغييرها بعد الدخول). تُطبَّق مرة واحدة لكل قيمة، ثم احذف المتغير.

### بيانات التجربة (منفصلة عن البيانات الفعلية)

```bash
DATA_DIR=./demo npm run demo          # ينشئ قاعدة تجربة في مجلد demo
DATA_DIR=./demo npm start
```

مستخدمو التجربة: `admin` / `Admin12345`، و`cashier`، `accountant`، `store`، `buyer`، `salem` (مندوب) بكلمة المرور `Passw0rd1`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل الخادم |
| `npm test` | تشغيل كل الاختبارات |
| `npm run backup` | نسخة احتياطية يدوية |
| `npm run verify-backup -- <النسخة>` | اختبار استرجاع نسخة في بيئة منفصلة |
| `npm run restore -- <النسخة>` | الاستعادة (والخادم متوقف) |
| `npm run reset-admin -- <كلمة مرور>` | إعادة تعيين كلمة مرور المدير من الخادم |
| `npm run demo` | إنشاء بيانات تجربة |

## متغيرات التشغيل

انظر `.env.example`. لا تُحفظ أي أسرار داخل الكود؛ البيانات والمرفقات والنسخ في مجلد `DATA_DIR` (الافتراضي `./data`).

## هيكل المشروع

```
src/
  db/schema.sql        مخطط قاعدة البيانات
  db/index.js          الفتح والترحيل والإعدادات الافتراضية
  core/                منطق العمل (كل عملية تفحص الصلاحية في الخادم وتنفذ ذريًا)
    sales.js purchases.js payments.js inventory.js stock.js finance.js reps.js
    ledger.js docs.js masters.js users.js reports.js backup.js importer.js permissions.js
    accounting.js einvoice.js whatsapp.js
  server.js            واجهة HTTP والحماية ومنع التكرار والجدولة
public/                الواجهة العربية (sw.js لعمل نقطة البيع دون اتصال)
scripts/               النسخ والاستعادة وبيانات التجربة
test/                  اختبارات القبول والاختبارات الإضافية
docs/                  الأدلة وتقرير الاختبارات والبنود المؤجلة ومحضر الاستلام
```
